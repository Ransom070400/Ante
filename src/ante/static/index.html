Start the 0G server

Ante talks to a local server that is backed by 0G. Start it in a terminal, then this page will connect on its own. 

ante-0g-server            # add --push-to-talk for the antenna trigger

If it starts but Ante still will not answer, the usual cause is an unfunded 0G sub-account. Each provider needs a locked reserve plus spendable headroom, so funding the bare minimum buys a single request. 

0g-compute-cli get-account

What runs where

Pipeline

Hearing is openai/whisper-large-v3 and thinking is glm-5.2, both on 0G. Speech synthesis is the one local stage, because the network has no speech synthesis provider at all.

A turn takes about thirteen seconds end to end. That is the network's round-trip rather than thinking time.
